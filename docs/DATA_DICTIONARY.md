# Витрина orders_mart

Одна строка на заказ. Исходные поля сохраняют определения Olist. Пустое значение не означает ноль. Суффикс `_cents` — целые центаво; `_brl` — бразильские реалы. В SQLite логические признаки хранятся как 0/1/NULL.

| Поле | Определение |
|---|---|
| `order_id` | Уникальный идентификатор заказа, ключ витрины |
| `customer_id` | Идентификатор записи покупателя для заказа |
| `order_status` | Статус заказа |
| `order_purchase_timestamp` | Дата и время покупки |
| `order_approved_at` | Дата и время подтверждения оплаты |
| `order_delivered_carrier_date` | Дата передачи перевозчику |
| `order_delivered_customer_date` | Фактическая дата получения |
| `order_estimated_delivery_date` | Обещанная дата доставки |
| `customer_unique_id` | Идентификатор покупателя между заказами |
| `customer_zip_code_prefix` | Первые пять цифр почтового индекса покупателя |
| `customer_city` | Город покупателя |
| `customer_state` | Штат покупателя |
| `item_count` | Количество строк товарных позиций |
| `seller_count` | Количество уникальных продавцов |
| `merchandise_cents` | Денежная сумма в целых центаво: merchandise |
| `freight_cents` | Денежная сумма в целых центаво: freight |
| `payment_count` | Количество записей оплат |
| `payment_cents` | Денежная сумма в целых центаво: payment |
| `review_score` | Выбранная последняя оценка |
| `review_answer_timestamp` | Дата и время ответа на выбранный отзыв |
| `first_review_score` | Первая оценка по времени ответа; альтернативное определение |
| `review_count` | Количество отзывов заказа |
| `merchandise_brl` | Стоимость товаров, BRL |
| `freight_brl` | Доставка, BRL |
| `payment_brl` | Оплаты, BRL |
| `in_scope` | Покупка входит в выбранный период |
| `purchase_month` | Месяц покупки YYYY-MM |
| `delivered` | Статус delivered |
| `delivery_valid` | Доставлен и даты пригодны для оценки срока |
| `delivery_eligible` | Входит в период и пригоден для оценки срока |
| `delivery_days` | Сутки от покупки до получения, дробное число |
| `delay_days` | Разница календарных дат получения и обещания; отрицательное значение — раньше срока |
| `late` | Просрочена обещанная календарная дата; пусто при непригодных датах |
| `low_review` | Оценка 1–2; пусто без оценки |
| `review_after_delivery` | Ответ на отзыв после получения |
| `payment_difference_cents` | Оплаты минус товары и доставка, центаво |
