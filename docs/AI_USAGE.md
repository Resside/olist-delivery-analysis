# Использование ИИ

При разработке использовался ChatGPT для проектирования структуры, подготовки Python и SQL, диагностики ошибок, расчётов, формулировки ограничений и оформления документации. ИИ участвовал существенно, включая написание кода.

Код выполнен на предоставленном наборе данных; результаты и проверки сохранены. Автоматическое выполнение не заменяет содержательного ревью. Пользователь подтвердил работу исходного учебного ноутбука и настройки окружения. Самостоятельная проверка пользователем всех выводов этой версии не заявляется.

Перед представлением проекта на собеседовании автору следует воспроизвести расчёты и уметь объяснить агрегацию до соединения, выбор знаменателей, различие оборота и выручки, временной порядок отзывов и ограничения причинных выводов. Учебные подсказки удалены из аналитического ноутбука; существенные методологические пояснения сохранены.
