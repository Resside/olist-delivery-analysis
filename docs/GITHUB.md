# Размещение проекта на GitHub

Создайте отдельный репозиторий для каждого проекта. Распакуйте архив и поместите содержимое его папки в корень репозитория, чтобы README.md находился сразу на главной странице.

Для локальной работы с Git из корня распакованного проекта:

```bash
git init
git add .
git status
git diff --cached --stat
git commit -m "Add reproducible analytics project"
git branch -M main
```

Затем подключите URL своего пустого репозитория как origin и отправьте main. Авторизация и URL зависят от вашего аккаунта. Перед первым коммитом при необходимости настройте имя и email Git.

Если загружаете файлы через веб-интерфейс, загружайте распакованные файлы и папки, а не единственный ZIP. Сохраните структуру и файл .gitignore. В веб-загрузке .gitignore сам по себе не исключает выбранные файлы, поэтому не добавляйте локальные окружения, исходные датасеты и SQLite вручную.

После публикации проверьте отображение README, графиков и ноутбука. Исходники данных устанавливаются по data/raw/README.md; вся логика пересчёта находится в проекте. Сохраните ссылки на источник, лицензию данных и описание участия ИИ.
